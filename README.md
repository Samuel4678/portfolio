# Samuel Mutunga: portfolio website
Static site (HTML, CSS, JavaScript). Runs on GitHub Pages with no build step.

## Publish
1. Create a GitHub repo (a nice choice is `Samuel4678.github.io` so the site lives at `https://samuel4678.github.io/`, or any repo name).
2. Upload the **contents** of this folder (keep `.nojekyll`).
3. Settings → Pages → Deploy from branch → `main` / `(root)`.

## Personalise
- **Photo:** save a headshot as `images/profile.jpg` (or .png/.webp). It replaces the "SM" circle automatically.
- **Resume:** export your resume as `resume.pdf` and put it in the site folder. A "Download resume" button appears automatically.
- **Contact:** WhatsApp number and email are at the top of `app.js` (`CONFIG`).
- **Text:** roles, skills, projects, education and "what to expect" are lists near the top of `app.js`.
- **Colours:** variables at the top of `styles.css` (`:root` is dark, `[data-theme="light"]` is light).

## Privacy
Your exam index numbers, registration number and the result slips themselves are deliberately NOT on the site. Keep it that way. Share full certificates only when an employer asks, directly.
